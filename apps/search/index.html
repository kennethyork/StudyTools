Search the Bible

Every word you type has to be in the verse, so shepherd want finds the verses with both. The whole Bible is searched, Apocrypha included, in the translations this site carries — and the index is a file on your own machine, so nothing you type leaves it.

The index is built by scripts/build-search.py and checked against the text by scripts/check-search.js. Searching narrows to verses containing every word; a verse reference in the box jumps instead.
