Your Data

Everything this site has saved in this browser — notes, plan ticks, memory cards, journals — in one place. Export it as a file, or carry it to another device as a short code. There is no account and no server: the two devices never meet, you hand the data from one to the other.

What is saved here

—

Take it with you

A sync code is the same data, compressed, to paste on another device — or to open as a link there. Codes can be long; they are meant to be copied, not typed.

Bring it in

Importing never replaces what is here: it is brought together. Notes take the more recently changed copy, reading-plan ticks add up, memory cards merge and keep the schedule further along, and anything that cannot be merged safely is left as it is and reported below.

    Nothing is uploaded, now or ever: the merge happens on this device, and the code travels by whatever you use to carry it — a message to yourself, a note, a QR code.

    Not yet offered: automatic syncing through an account, or through a file in a cloud folder. Both would need something of yours to sit between the devices, which this site does not have.
