Can this machine run the model?

The reader can offer a small language model to ask about a verse. It runs on your own device through WebGPU, which means your machine has to be able to run it — so this page checks, and if it cannot, says which part is missing and what fixes it. Nothing is downloaded here. The model is fetched only when you turn it on in the reader.

What the model needs

WebGPU
In Chrome and Edge 121+, Safari 26 and Firefox 141+. On Linux, Chrome needs Vulkan to be available to it before it will use the GPU.
An adapter
WebGPU being present is not the same as a GPU being usable: the browser also has to find an adapter. When it does not, that is a driver matter, not a browser version one.
Memory
The default model is about 1.8 GB on disk and takes a few gigabytes of working memory while it runs. Smaller ones are offered in the reader.
Once
The download happens once per browser; after that it runs offline, and nothing you type leaves the machine.
