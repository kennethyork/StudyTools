About StudyTools

Free Bible study tools that run entirely in your browser — no accounts, no tracking, no server.

What this is

StudyTools is a collection of small, dependency-free Bible study apps. Everything is static HTML, CSS and JavaScript, so the whole site can be served from any static host with no build step and no backend.

Notes, journals, memory decks and study progress are saved in your browser's local storage and never leave your device.

On numbering

All three use the same chapter and verse numbering, so a reference lines up exactly between them. Editions that follow Vulgate numbering — where Psalm 22 is the Hebrew Psalm 23 — were deliberately left out, because they would quietly show the wrong text side by side.

The World English Bible is not copyrighted; “World English Bible” is a trademark of eBible.org, and a modified text should not carry that name. Its full notice is at eBible.org.

The per-book text under data/bible/ is built from these sources by the scripts in scripts/.

Privacy

Nothing is uploaded. There are no accounts, no cookies, no analytics and no server to talk to. Everything you type — notes, journals, memory decks, saved ideas — stays in your browser's local storage, and clearing your browser data removes it.

Scripture and study data are public domain or openly licensed, as listed above. See the repository README for the full attribution list.
